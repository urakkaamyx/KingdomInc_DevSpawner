DevSpawner 1.3.0
By rockyamyx / Urakka

Generate any item without normal production inputs using Kingdom Inc's Spawner.

REQUIREMENTS
Foundation 0.5.0 or newer and BepInEx 5, installed separately.
BepInEx: https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.6

INSTALL
1. Close Kingdom Inc.
2. Install the requirements if needed.
3. Extract this ZIP beside KingdomInc.exe.
4. The plugin belongs at BepInEx/plugins/DevSpawner/DevSpawner.dll.
5. Start the game. Open Tech Tree > Mods and unlock DevSpawner for free.
6. Build Spawner from the Resource menu. Normal building costs apply.

Existing kingdoms with placed Spawners keep access automatically.

USE
Click the Spawner's + or selected item icon to open the picker. Search by
item name or ID and click a row to select what to generate. Each row shows
its gold value at 100% quality before shop bonuses, or Not sellable.

The selected item's icon and name appear on the node. Hover for its gold
value. Your selection is saved. Changing items clears pending output and
keeps connected pipes; selecting the same item keeps pending output.
An unset Spawner can also learn its item from a connected input.
Close, Escape, right-click or click outside to cancel the picker.

UPDATE OR REMOVE
Close the game before replacing or deleting the DLL. To remove, delete
BepInEx/plugins/DevSpawner/DevSpawner.dll. Existing Spawners keep their
selected item but stop generating. Items already produced remain.
